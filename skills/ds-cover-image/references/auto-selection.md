# 自动选维度规则

读懂标题里的信号，按下面对照表选维度。给不出明确答案的维度留给用户在 Step 2 选。

|---|---|

## 大圣公众号场景的快速判断

读完标题先问自己 3 个问题：

1. **这篇文章是技术 / 故事 / 观点 / 教程 / 产品里的哪一类？** → 锁定 Type + Palette 大方向
2. **标题里有没有具体物体可以画？** → 有就用 `metaphor`，没有就用 `typography` 或 `minimal`
3. **读者打开后期望什么情绪？** → 温暖 → warm/hand-drawn；锋利 → mono/flat-vector；庄严 → dark/digital

3 个问题答完，5 维度基本就定了。
