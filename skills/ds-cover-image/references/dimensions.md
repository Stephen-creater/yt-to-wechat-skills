# 5 个维度详解

## Type 构图

| Type | 描述 | 适合 |
|---|---|---|
| `hero` | 大焦点视觉（占 60-70%），标题压在视觉上，戏剧化构图 | 产品发布、品牌宣传、重大公告 |
| `conceptual` | 抽象形状代表核心概念，信息层级清晰，留白区分明 | 技术文章、方法论、架构设计 |
| `typography` | 标题为主体（占 40%+），辅助视觉极简 | 观点文、金句、洞察 |
| `metaphor` | 用具体物体表达抽象概念，象征元素 | 哲思、成长、个人发展 |
| `scene` | 氛围场景，叙事感，意境光影 | 故事、旅行、生活方式 |
| `minimal` | 单一焦点元素，大量留白（60%+），只留必要形状 | 禅意、聚焦、核心概念 |

## Palette 配色

| Palette | 主色调 | 适合 |
|---|---|---|
| `warm` | 米褐 / 砖红 / 橙黄 / 暖灰 | 个人故事、情感、生活方式 |
| `elegant` | 深墨绿 / 香槟金 / 米白 / 深棕 | 商业、专业、思想领导力、奢华 |
| `cool` | 海军蓝 / 青绿 / 浅灰 / 银白 | 架构、系统、API、技术、代码 |
| `dark` | 深炭黑 / 紫罗兰 / 翡翠 / 金色高光 | 娱乐、高端、电影感、深色模式 |
| `earth` | 大地棕 / 苔绿 / 沙黄 / 砖红 | 自然、健康、生态、有机、旅行 |
| `vivid` | 高饱和红 / 黄 / 蓝 / 品红 | 产品发布、游戏、促销、活动 |
| `pastel` | 薄荷绿 / 浅粉 / 淡蓝 / 奶黄 | 奇幻、儿童、温柔、创意 |
| `mono` | 黑 / 白 / 灰阶 + 单色重点 | 禅意、聚焦、纯粹、极简 |
| `retro` | 砖橙 / 芥末黄 / 鸭蛋青 / 奶咖 | 历史、复古、经典、探索 |
| `duotone` | 两种强对比色（如紫+黄、青+橙）+ 纯色背景 | 电影海报、专辑封面、剧照感 |
| `macaron` | 薄荷 / 桃粉 / 奶油黄 / 薰衣草 / 天蓝 | 教育、教程、知识、概念解释 |

## Rendering 笔法

| Rendering | 特征 | 适合 |
|---|---|---|
| `flat-vector` | 干净几何形状，纯色填充，无纹理无渐变 | 干净、现代、科技、公众号、信息图 |
| `hand-drawn` | 手绘线条、有笔触感、不完美的边缘 | 笔记感、个人、随性、涂鸦、温暖 |
| `painterly` | 水彩 / 油画感、柔和过渡、艺术感 | 艺术、梦幻、创意、奇幻 |
| `digital` | 精致渲染、清晰阴影、商业插画质感 | 数据、SaaS、企业、专业 |
| `pixel` | 像素方块、8-bit / 16-bit 复古 | 游戏、复古、怀旧 |
| `chalk` | 粉笔质感、黑板背景、白色描边 | 教育、教程、课堂、教学 |
| `screen-print` | 丝网印刷感、有限色、剪影、纹理粗 | 海报、电影、专辑、复古印刷 |

## Text 文字密度

| Level | 描述 | 视觉占比 |
|---|---|---|
| `none` | 无文字，全视觉 | 视觉 100% |
| `title-only` | 单一标题 | 视觉 85% |
| `title-subtitle` | 标题 + 副标题 | 视觉 75% |
| `text-rich` | 标题 + 副标题 + 2-4 个关键词标签 | 视觉 60% |

公众号封面默认 `title-only`。

## Mood 情绪强度

| Mood | 对比度 | 饱和度 | 视觉重量 | 整体气质 |
|---|---|---|---|---|
| `subtle` | 降低 20-30% | 降饱和 20-30% | 更轻的笔画/填充 | 安静、克制、高级 |
| `balanced` | 标准 | 标准 | 标准 | 平衡、通用 |
| `bold` | 提高 20-30% | 增饱和 20-30% | 更重的笔画/填充 | 动感、张力、抢眼 |

## Font 字体倾向

| Font | 特征 | 适合 |
|---|---|---|
| `clean` | 现代无衬线（思源黑体类） | 技术、专业、干净、现代、极简、数据 |
| `handwritten` | 手写体 | 个人、生活方式、温暖、友好、故事 |
| `serif` | 衬线体（思源宋体类） | 编辑、学术、奢华、经典、文学 |
| `display` | 大号装饰字体 | 公告、娱乐、促销、抢眼、活动、游戏 |
